# 上海迪士尼一日行程 Query 数据集

共 **1,796 条去重 query**，沿用既有 rewrite-v4 输入，不重新改写问题或约束。原 1,800 条候选中的 4 条完全重复项未收录。

| 文件 | 条数 | 用途 |
| --- | ---: | --- |
| train.jsonl | 1,437 | 训练输入，与本地已审核答案的原输入逐条核对一致 |
| validation.jsonl | 180 | 验证输入 |
| test.jsonl | 179 | 测试输入 |

每行一个 JSON 对象：`id`、`split`、`familyId`、`theme`、`difficultyHint`、`query`、`profile`、`planningConstraints`。

- `query` 是用户需求；`profile` 是同行人员、权益、日期等结构化档案；`planningConstraints` 是起点、项目偏好和排队上限等约束。
- `familyId` 为发布版本重新编号的来源分组，保留同源样本分组关系；同一分组不跨训练、验证、测试集。这不等于已证明所有语义近似样本完全隔离。
- 日期、预算、到离园时刻等包含合成扩展值；这些是生成的规划场景，不应称为游客原话。
- 输入中可能存在冲突或缺失条件，用于评估说明取舍和完成其余规划的能力；不保证每条需求能够全部满足。
- 本次只发布 query，不含原始帖子、来源账号/帖子标识、密钥、教师答案或模型权重。答案审核通过与训练批准是不同状态。

各文件数量、大小和 SHA-256 位于 `manifest.json`。训练时保持既有 split，不把验证/测试 query 混入训练集。
